## What's new in 0.10.0

### Firmware sources
- Choose a firmware source and build channel on the Firmware tab. Sources are set in `appsettings.json`, so new ones can be added without a new Companion release.
- New Experimental track (Preferences > Preferred firmware track) adds community builds from Greg APFPV and Mabur alongside OpenIPC Builder. Stable stays the default.
- Mabur builds are listed by release, newest first, so you can pick a specific build or follow the latest one.
- A warning is shown while an experimental source is selected. Experimental firmware is untested and may be buggy, lose your settings, or brick the device. Use it at your own risk, and keep a backup and a way to recover the device.

### Fixes
- Connecting no longer shows a "Hostname Error!" prompt for devices that use the new SoC-sensor hostnames (for example `ssc338q-imx415`).
- Updated SSH.NET to 2026.0.0 to fix high-severity security issues. Remote file paths are now safely quoted when copying files to the device.
- Fixed download links for the latest firmware release.
- macOS: the app is now named OpenIPC Companion.

Full list of changes: https://github.com/OpenIPC/companion/compare/release-v0.9.6...release-v0.10.0
